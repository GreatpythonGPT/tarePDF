# tarePDF 2

把设计效果图整理成适合手机、平板连续阅读的演示 PDF。所有内容在本机处理，运行时无需联网。

**主流程：导入图片 → 整理顺序 → 输出设置 → 预览检查 → 保存 PDF。**

2.0 已彻底移除调色、锐化、曲线、标注及相关图片编辑模块。软件只管理图片和文稿输出；不会改写原图。

## 工作方式

图片管理支持 JPG、PNG、WEBP、BMP、GIF（首帧），文件选择与外部拖入、内容去重、Shift 连选、Ctrl 多选、框选、整组拖拽、文件名自然排序。移除和排序等列表操作可撤销/重做，保留最近 20 步。Delete 仅在图片工作区内生效，输入框和设置页不会触发删图。

默认导出整个有序列表。顶部可显式切换「仅选中图片」，导出前显示图片数和总页数；选中状态不会暗中改变默认导出范围。

输出宽度为 100–5000 px，默认 1080。图片各占一页，高度按原比例计算，透明区域铺白底。可设置图片质量；JPEG 编码意味着文件不会逐字节保留原图，原始文件不受影响。这是屏幕演示工具，不是印刷尺寸或色彩管理工具。PDF 页面点数沿用输出像素数，仅规定阅读比例，不代表印刷 DPI。

标题页始终在最前，高度 500；支持中文、手动换行、自动换行和长标题缩小。使用本机已安装字体；字体不存在时采用系统回退字体。标题和文字水印栅格化，不作为可搜索文字嵌入。不随软件分发系统字体文件。

图片水印 A/B 和文字水印 C/D 可分别设置位置、边距、尺寸/字号、不透明度等参数。每张图片有独立开关，也可对选中图片批量启停。超大水印会等比缩小到页面内。图片水印 PNG 随配置保存，移动原文件后仍可使用。缺失或损坏的已启用水印会阻止输出，不能静默漏印。

可选白色分隔页只插在相邻图片之间。预览与导出共用页面计划和图像生成器，包含标题和分隔页。长文稿按需渲染预览，避免同时保留所有页面画布。

## 安装与运行

开发环境：Node.js 22.16 或更高版本。Windows 为主要使用平台。

```sh
npm ci
npm start
```

开发者工具：`npm run dev`。第一次安装/启动开发环境需要下载依赖和 Electron；安装完成后的应用运行与 PDF 导出不需要网络。

```sh
npm run check
npm test
npm run test:e2e
npm run dist
```

Linux 无桌面测试时运行 `xvfb-run -a npm run test:e2e`。Windows 打包见 [BUILD_GUIDE.md](BUILD_GUIDE.md)。GitHub Actions 自动运行 Linux/Windows 测试和 Windows 便携版构建，产物在对应运行的 Artifacts 中。

## 保存、迁移与边界

输出设置自动写入本机用户数据目录的 `workspace-v2.json`。命名配置最多 50 个；配置包含水印和输出样式，不包含图片列表。**关闭后图片与排序不会自动恢复**，关闭确认会说明这一点；关闭前会等待最近设置保存。程序不提供项目文件保存功能。

初次运行 2.0 会读取同一用户数据目录的旧 `config.json`，迁移设置与命名配置，原文件保持不变。旧版水印只有路径，需要重新选择一次，迁移后会明确提示。无通用路径读取接口。损坏的新配置先备份再恢复默认；更高版本配置以只读方式打开，防止误覆盖。

PDF 通过系统保存对话框选定位置，写入临时文件并原子替换；取消不会创建文件，失败不会报告成功。只能通过应用打开本次实际成功保存的 PDF。Windows 文件被其他软件锁定时可能无法覆盖，会显示错误，原文件不会先被删除。

为控制内存，当前限制为：每份最多 500 张；单张源文件 64 MB / 6000 万像素；单页输出最多 3200 万像素、最长边 14400；PDF 最大 256 MB。PNG 水印约 4.5 MB，全部设置合计最多 32 MB。超限会明确报错，可降低输出宽度或拆分文稿。上限是防护值，不代表所有接近上限的组合均经过压力验证。

## 实现与测试

- `src/shared/model.js`：设置校验、旧配置迁移、选择排序、页面计划、图片尺寸预检。
- `src/services.js`：原子保存、配置存储、PDF 保存状态、IPC 来源校验。
- `src/main.js` / `preload.js`：隔离与沙箱、受限本地资源协议、窄接口和原生对话框。
- `src/renderer/scripts/app.js`：一个初始化入口、图片列表、设置、预览生命周期。
- `src/renderer/scripts/document.js`：预览和 PDF 共享的页面渲染。
- `tests/`：直接测试真实模块与完整 Electron 应用；不以旧代码片段代替回归测试。

验证范围、架构取舍及人工验收清单见 [docs/V2_CHANGELOG.md](docs/V2_CHANGELOG.md)。根目录旧 DEVELOPMENT_LOG / FONT_FIX_SUMMARY 等为 1.x 历史记录，不代表 2.0 的功能范围。
