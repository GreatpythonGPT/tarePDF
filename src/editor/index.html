A LITTLE GUIDE

从一张图，到一组作品

  1. 导入图片

    左侧添加图片，也可以把文件直接拖进窗口。点击页面切换，勾选框用于批量操作。

  2. 完成你的排版

    添加文字、图形，或从“排版”选一个起点。“标注”提供直线、折线、箭头和编号模板，可点选或拖入；右侧分别调角度、段长和文字位置。双击文字编辑，角点缩放整组标注。

  3. 让几张图一起更新

    勾选需要的页面，点击“共用当前排版”。此后编辑任何一个共享元素，绑定的页面都会同步。解除共享后可单独编辑。

  4. 保存，再分享

    “保存作品”保留全部可编辑内容；“导出作品”生成 PDF 或当前页 PNG。关闭后也可恢复最近的自动保存。
