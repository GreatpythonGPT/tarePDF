# 2.0 重构记录

基线：5edadb96adae66f1766a3a6c702edbe23998cab2。需求：全部取消图片编辑，保留图片整理与演示 PDF 输出。

## 变化

删除 imageProcessor 和旧全局管理器、旧事件绑定、图像调色、曲线、锐化、标注及相关界面/CSS。图片编辑类故障通过删除功能消除，不再为已经取消的功能续写实现。

界面重整为三个工作区：整理图片、输出设置、预览检查。新增明确导出范围、页数提示、按内容去重、自然排序、20 步列表撤销/重做、稳定 ID 和可取消任务。删除只移除文稿条目，不删除磁盘文件。

安全与可靠性：单一初始化，严格字段校验，文本用 DOM textContent 写入；本地 pdf-lib、CSP、沙箱、隔离、资源白名单；取消通用路径读写、任意 IPC 调用和远程脚本。原子 PDF/配置写入、保存/取消/失败三类结果、来源窗口与顶层 frame 验证。打开失败与已保存状态分开。关闭前 flush 最新设置，失败时明确提示。

页面计划统一用于预览和导出。标题高 500、比例保持、透明图白底、零不透明度有效、缺失水印阻止导出。PNG 水印内置于设置，旧路径迁移不读取文件。预览按需渲染并回收 Blob URL，源图片使用不可变 File/Blob。

移除未使用的 sharp、electron-store、electron-packager。Electron 28 升级到固定的 44.4.3；pdf-lib 固定 1.17.1，构建依赖与测试依赖使用锁文件。生产包不再分发旧系统字体。
