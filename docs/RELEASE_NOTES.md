# Tare Studio 交付说明

## 2.2 · 恢复批量图片编排

2.0 / 2.1 的主界面偏向单图编辑，尺寸设置也变成了限制最长边，未完整保留早期“导入一批图、统一宽度、拖动排序、加标题和横条”的流程。本版恢复这套流程，并与单图编辑共存。

- 导入多张图片后自动进入“整组编排”，默认宽度 1080 px。支持 100–5000 px 自定义宽度，横图、竖图和小图均按比例缩放；原图保留，PDF 内嵌图片与 PNG 实际使用指定像素宽度。
- 连续预览与缩略图排序可切换。两种视图都支持单张、多张原生拖动排序，支持撤销重做；新导入时只选中第一张，避免默认全选导致拖动一张时整组移动。
- 开头标题条可设置文字、高度、字号、对齐、字色和底色，支持换行和自动适配；图片间横条可设置高度和颜色。编辑时直接预览，导出顺序一致，开头和末尾不额外插入分隔横条。
- 双击图片或点击“编辑此图”进入原有画布，文字、标注、调色、裁剪和共享排版继续可用。返回整组后，单图修改立即反映到预览。
- 所有整组设置、图片顺序和共享关系随 `.tare` 保存、自动恢复和撤销。2.0 / 2.1 作品保留原有最长边选项，也可切换到统一宽度。
- 整组预览只处理可见区域及附近图片，缓存缩略图；超大输出会明确提示降低宽度或裁剪，不会悄悄缩成不一致的宽度。

## 2.1 · 模板标注工具箱

原先的箭头与说明文字需要分开摆放，折线也没有独立参数。现在标注是一个完整的可编辑对象，模板可直接点击添加或拖入画布；拖入位置就是指示端。

- 六种模板：直线指示、箭头指示、斜折线指示、直角指示、双向尺寸线、编号指示。选中后可切换样式，保留说明文字。
- 斜段角度、第一段长度和横段长度独立调整；常用角度快捷按钮、四向延伸。横竖页面及不同输出分辨率使用相同几何规则，角度不会被页面比例拉歪。
- 指示端 / 线尾端可选圆点、空心圆、箭头、短横杠等；可调端点大小、实线 / 虚线 / 点线、编号文字。
- 说明可置于线上方、下方、末端或线中，可隐藏；支持多行、宽度、间距、衬底颜色、字号、对齐及粗体。双击画布标注可直接编辑说明。
- 整组拖动、等比例缩放、旋转、复制、锁定、图层、共享、解绑、撤销重做、保存恢复和导出均接入原有编辑流程。缩放到参数边界时整组约束，不改变折线比例。
- 内置“三款配色台灯”标注示例，左侧“标注 → 体验产品标注示例”可直接打开；全部资源本地生成，不需要联网。
- 2.0 作品继续兼容；带新标注的作品需要 2.1 或更新版本。尺寸线文字由用户填写，不测量图中实物。

本次没有新增外部依赖，仍使用随程序打包的 Konva。标注几何、绘制和属性面板分为三个独立模块；画布、缩略图、PNG 和 PDF 共用标注绘制代码。共享更新复制嵌套参数，解除同步后不会残留可变对象引用。

## 2.0 · 画布编辑器重构

本次将原来的图片处理与 PDF 工具重构为本地画布编辑器。重点是保留可编辑文档、明确共享范围、避免图片串写和误删，并使导出与画布使用同一套绘制代码。

## 已完成的主要能力

- 三栏中文工作区、拖动缩放旋转、画布内文字输入、图层、锁定、对齐辅助线、缩放和平移。
- 文字、矩形、圆形、箭头、透明贴图；三套可编辑排版起点。
- 整套排版共享与单个元素共享；修改、解除绑定、撤销重做均可保存和恢复。
- 六项非破坏性调色、四套调色预设、裁剪、取景位置、90° 旋转；调色可批量复制，但与排版共享独立。
- 勾选、Shift 连选、批量拖动排序、复制、删除、历史记录。
- `.tare` 作品保存、另存、打开、自动恢复；中文封面、分页、选定范围 PDF 和 PNG 导出。

## 原问题的处理

| 原问题 | 新实现 |
| --- | --- |
| 模块重复初始化、事件未绑定、首次进入无图片 | 单一应用入口，明确字体和文档加载完成后进入就绪状态 |
| 输入框 Backspace 误删整组图片 | 编辑控件独立处理键盘，画布删除只针对选中元素；页面删除有专用按钮 |
| 切图时旧回调写错图、索引漂移 | 稳定页面 ID、请求序号、固定任务快照，过期结果丢弃 |
| 应用调色覆盖旧调整和标注 | 原图不变，参数和对象独立保存，每次从原图重建画面 |
| 标注撤销不可用、prompt 不受 Electron 支持 | Konva 可编辑对象、真实文本编辑控件、文档级历史 |
| 缩放坐标错误、窗口 resize 清空内容 | 统一文档坐标与画布变换，ResizeObserver 只调整视图 |
| 批量应用是空实现 | 可持久化的共享布局与共享元素关系 |
| 锐化黑边或透明边、全分辨率运算卡主线程 | 后台 Worker，限制预览分辨率，边缘钳制并保留 alpha |
| 文件名和配置名 HTML 注入 | 用户输入均以文本或控件值使用，CSP 禁止远程和内联脚本 |
| 通用 IPC 任意路径读写、死接口 | 只提供作品和导出用途的固定接口，文件路径由原生对话框取得 |
| PDF 双击重入锁错误、取消仍提示成功 | 操作入口独占、固定快照、取消与失败单独处理 |
| 透明图变黑、中文字体或 CDN 不可用 | 同一画布合成器、显式底色、打包字体与 pdf-lib，离线运行 |
| 依赖和构建脚本失配 | 锁定依赖、删除无效构建钩子和闲置依赖、替换过时指南 |

旧代码与重复样式已移除；旧文档移到 `docs/legacy/` 保留历史。原有用户设置不覆盖，但不会自动转换成新作品模型。
